## Descarte — barrera de transacción envolvente
`reject_attachment_offline` y `retry_rejected_discard_offline` impiden destruir bytes cuando `connection.in_atomic_block` es verdadero. La primera función confirma el estado `rejected` en una transacción propia antes de descartar el cifrado; las pruebas de este módulo pasan a `TransactionTestCase` para comprobar un commit real y el bloqueo dentro de `atomic()`. Añadida regresión transaccional. **Pendiente de ejecución del gate integral**, por tanto no se afirma validación. Persisten riesgos de caída entre commit y descarte: se requiere reconciliación operacional persistente/outbox para producción. No existe endpoint público ni autorización de despliegue.
