# B13C — Persistencia Ed25519 en PG17 temporal

La migración independiente 0006 amplía el campo de firma
de 64 a 128 caracteres. Conserva la capacidad de almacenar
las firmas HMAC previas de 64 caracteres.

La nueva recepción offline acepta únicamente evidencias
Ed25519 válidas, firmadas para el documento y SHA-256
esperados, dentro de su ventana temporal.

La persistencia utiliza la barrera cooperativa B06B,
bloqueo de fila y transacción atómica. No permite
duplicados ni cambia el estado de cuarentena.

El circuito HMAC previo no se modifica.

Esta separación es experimental: todavía no existe
aislamiento operacional del proceso firmante ni gestión
de claves públicas por versión o rotación.

La migración solo se ensaya en PostgreSQL 17 temporal.
