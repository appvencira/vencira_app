# VENCIRA — B13B Ed25519

Contrato experimental de evidencia asimétrica de escaneo.

- El firmante utiliza clave privada Ed25519.
- El receptor únicamente necesita los 32 bytes de clave pública.
- El mensaje tiene dominio y versión explícitos.
- La firma cubre identidad del objeto, SHA-256,
  resultado, motor y momento del escaneo.
- Se rechazan firmas falsas, objetos diferentes,
  estados distintos a cuarentena y evidencias caducadas.

No se genera ninguna clave privada persistente ni
se configura un servicio real.

La firma Ed25519 aún no está conectada al modelo
AttachmentScanEvidence ni sustituye HMAC en B13A.
La separación física de procesos, la custodia de
claves y las pruebas PG17 continúan pendientes.

Las operaciones de documentos siguen cerradas.
